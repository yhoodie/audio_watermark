# 需求文档

## 1. 应用概述

### 1.1 应用名称
音频数字水印工具

### 1.2 应用描述
一款桌面客户端工具，支持在音频文件中嵌入数字水印（文字、图像、音频），以及从音频文件中提取已嵌入的水印。

## 2. 用户与使用场景

### 2.1 目标用户
- 需要对音频文件进行版权保护的内容创作者
- 需要在音频中隐藏信息的用户
- 需要验证音频来源或完整性的用户

### 2.2 核心使用场景
- 场景1：用户在发布音频作品前，嵌入版权水印信息
- 场景2：用户收到音频文件后,提取水印验证来源或版权信息

## 3. 页面结构与功能说明

### 3.1 页面结构

```
音频数字水印工具
├── 界面1：水印嵌入
└── 界面2：水印提取
```

### 3.2 界面1：水印嵌入

#### 3.2.1 功能说明
- 上传载体音频文件
- 在线播放试听载体音频
- 选择水印类型（文字/图像/音频）
- 上传或输入水印内容
- 在线播放试听水印音频（当水印类型为音频时）
- 执行水印嵌入处理
- 输出嵌入水印后的音频文件
- 在线播放试听嵌入水印后的音频

#### 3.2.2 载体上传
- 支持上传音频文件作为载体
- 显示已上传文件名称

#### 3.2.3 载体音频播放
- 上传载体音频后，显示音频播放器
- 播放器功能：
  - 播放/暂停控制按钮
  - 进度条显示与拖动定位
  - 时间码显示（当前播放时间/总时长）
- 播放器风格与整体界面一致

#### 3.2.4 水印类型选择
- 提供三种水印类型选项：文字、图像、音频
- 用户选择其中一种类型

#### 3.2.5 水印内容输入
- 文字类型：提供文本输入框，用户输入文字内容
- 图像类型：提供图像文件上传功能，显示已上传图像文件名称
- 音频类型：
  - 提供音频文件上传功能，显示已上传音频文件名称
  - 上传水印音频后，显示音频播放器
  - 播放器功能：
    - 播放/暂停控制按钮
    - 进度条显示与拖动定位
    - 时间码显示（当前播放时间/总时长）
  - 播放器风格与整体界面一致

#### 3.2.6 嵌入处理
- 提供「开始嵌入」按钮
- 点击后执行水印嵌入处理
- 显示处理进度或状态提示

#### 3.2.7 结果输出
- 处理完成后，提供下载嵌入水印后的音频文件功能
- 显示输出文件名称

#### 3.2.8 输出音频播放
- 嵌入处理完成后，显示输出音频播放器
- 播放器功能：
  - 播放/暂停控制按钮
  - 进度条显示与拖动定位
  - 时间码显示（当前播放时间/总时长）
- 播放器风格与整体界面一致
- 用户可对比嵌入前后的听觉效果

### 3.3 界面2：水印提取

#### 3.3.1 功能说明
- 上传包含水印的音频文件
- 在线播放试听上传的音频
- 执行水印提取处理
- 输出提取到的水印内容

#### 3.3.2 音频上传
- 支持上传音频文件
- 显示已上传文件名称

#### 3.3.3 上传音频播放
- 上传音频后，显示音频播放器
- 播放器功能：
  - 播放/暂停控制按钮
  - 进度条显示与拖动定位
  - 时间码显示（当前播放时间/总时长）
- 播放器风格与整体界面一致

#### 3.3.4 提取处理
- 提供「开始提取」按钮
- 点击后执行水印提取处理
- 显示处理进度或状态提示

#### 3.3.5 结果输出
- 处理完成后，展示提取到的水印内容
- 文字水印：直接显示文字内容
- 图像水印：显示图像预览，提供下载功能
- 音频水印：提供播放功能，提供下载功能

## 4. 业务规则与逻辑

### 4.1 水印嵌入规则
- 载体文件必须为音频格式
- 水印类型与水印内容必须匹配（选择文字类型时必须输入文字，选择图像/音频类型时必须上传对应文件）
- 嵌入处理完成后生成新的音频文件，原载体文件不受影响

### 4.2 水印提取规则
- 上传的音频文件必须包含已嵌入的水印
- 提取结果根据水印类型展示对应内容

### 4.3 文件处理规则
- 嵌入水印后的音频文件保持原音频格式
- 输出文件命名规则：原文件名_watermarked

### 4.4 音频播放规则
- 播放器仅在音频文件上传成功后显示
- 播放器支持播放/暂停切换
- 进度条可拖动定位到指定播放位置
- 时间码格式为 mm:ss / mm:ss（当前时间/总时长）

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理方式 |
|------|----------|----------|
| 水印嵌入 | 未上传载体音频文件 | 提示用户上传载体文件 |
| 水印嵌入 | 未选择水印类型 | 提示用户选择水印类型 |
| 水印嵌入 | 未输入/上传水印内容 | 提示用户输入或上传水印内容 |
| 水印嵌入 | 上传文件格式不支持 | 提示用户上传正确格式的文件 |
| 水印嵌入 | 处理失败 | 提示处理失败，建议重试 |
| 水印提取 | 未上传音频文件 | 提示用户上传音频文件 |
| 水印提取 | 音频文件不包含水印 | 提示未检测到水印信息 |
| 水印提取 | 处理失败 | 提示处理失败，建议重试 |
| 音频播放 | 音频文件加载失败 | 提示音频加载失败 |

## 6. 验收标准

1. 用户打开应用，进入水印嵌入界面
2. 用户上传载体音频文件
3. 用户点击播放按钮试听载体音频
4. 用户选择水印类型为文字，输入水印文字内容
5. 用户点击「开始嵌入」按钮，等待处理完成
6. 用户点击播放按钮试听嵌入水印后的音频，对比嵌入前后听觉效果
7. 用户下载嵌入水印后的音频文件
8. 用户切换到水印提取界面
9. 用户上传刚才生成的音频文件
10. 用户点击播放按钮试听上传的音频
11. 用户点击「开始提取」按钮，等待处理完成
12. 用户查看提取到的水印文字内容，与步骤4输入的内容一致
